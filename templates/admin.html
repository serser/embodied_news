Paste a blog URL. The server tries a deterministic scraper first (RSS / Next.js / HTML heuristics), then falls back to MiMo if that fails. Back to feed

How this works
  1. Preview: server tries generic scraper (RSS → Next.js → HTML). Shows first 5 posts.
  2. If generic returns < 3 posts, server invokes MiMo to write a bespoke scraper (takes ~30–60s).
  3. Generated code is validated (AST + import allowlist), saved to sources/, and executed once.
  4. Save: registers the source and refreshes the feed cache.
